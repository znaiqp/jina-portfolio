# Jina Park — Portfolio

실제 업로드된 HANGANG TUH, VEGEMIL, WEAVE KITCHEN은 Team project로 표시합니다. 각 프로젝트의 담당 역할은 사용자 제공 내용을 `dist/project-credits.js`에 기록했으며 상세 페이지의 My role 목록에 표시합니다. 베지밀 썸네일은 제공된 이미지 중 주머니 속 패키지 장면(`vegemil-pocket`)으로 홈·Projects·Index에서 통일합니다.

첨부 MP4 영상은 사이트 안에서 재생합니다. 영상 파일 열기 링크를 제공하지 않으며 `controlslist="nodownload"`로 지원 브라우저의 다운로드 메뉴를 숨기고, 영상 영역의 우클릭 메뉴를 막습니다. 이는 일반 UI에서 저장 경로를 줄이는 조치이며 웹 재생 파일의 추출이나 화면 녹화를 완전히 방지하는 DRM은 아닙니다.

베지밀 그래픽 시스템 이미지 다음에는 `베지밀 긴 모티프.png`의 웹용 사본을 표시합니다. PC에서는 마우스를 올리거나 키보드로 초점을 주면 오른쪽으로 초당 40px 이동하며, 벗어나면 멈춥니다. 좌우 방향키와 Home/End로도 이동할 수 있습니다. 모바일·터치 화면에서는 스크롤에 맞춰 이미지가 잠시 고정된 채 오른쪽으로 이동합니다. 모션 줄이기 설정에서는 자동 이동 대신 수동 가로 스크롤을 제공합니다. `dist/motif.js`가 애니메이션을 관리하며 페이지 이동 시 리스너와 프레임을 해제합니다.

ORKR의 절제된 타이포그래피, 분할 레이아웃, 고정 내비게이션과 프로젝트 중심 탐색에서 영감을 얻은 정적 포트폴리오입니다.

실행: `node server.mjs` → http://127.0.0.1:4173

배포할 파일은 `dist/`에 있습니다. 의존성이나 빌드 과정이 필요하지 않습니다.

- `dist/app.js`: 프로젝트 목록, 소개 문구, 화면과 인터랙션
- `dist/style.css`: 반응형 레이아웃, 호버와 모션
- `dist/index.html`: 사이트 이름, 메타데이터와 내비게이션
- `dist/profile.js`: 이름, 이메일, 소셜 링크, 학력·경력·수상 데이터
- `dist/cv.css`: 2열 CV 레이아웃

CV는 `#/cv`이며 이전 `#/info` 링크도 CV로 연결됩니다. Close 또는 Escape로 이전 화면에 돌아갑니다. 학력 1건, 경력 2건, 수상 3건은 사용자가 제공한 LinkedIn 캡처에서 옮겼습니다. 소셜 링크는 사용자가 제공한 주소의 추적 쿼리만 제거해 연결했습니다. 사이트 이름은 Jina Park이며, 프로젝트명 HANGANG TUH는 유지됩니다.

한강터 프로젝트는 제공된 이미지 7장, WEAVE KITCHEN 프로젝트는 제공된 설명과 이미지 8장으로 구성했습니다. 베지밀은 제공된 설명과 수상 내역, 이미지 22장 및 MP4 영상으로 구성했습니다. 연락처와 CV는 `dist/profile.js`에서 관리합니다.

홈 왼쪽 목록은 한강터로 시작합니다. 홈의 좌우 목록은 각각 독립적으로 스크롤되며, 프로젝트 제목이 각 목록 상단에 고정됩니다. 모바일은 하나의 세로 문서로 전환됩니다. 상단으로 이동하면 양쪽 목록이 함께 초기화되고, 상세 페이지에서 돌아오면 스크롤 위치가 복원됩니다.

한강터 영상은 `https://youtu.be/XqM5RE9RETE`의 클릭 재생 YouTube 임베드입니다. 홈 오른쪽 목록과 한강터 상세 페이지에서 재생할 수 있습니다. 외부 YouTube 링크도 제공됩니다.

WEAVE KITCHEN 영상은 `https://youtu.be/OfqosCr1TNE`이며 위브 키친 상세 페이지에서 클릭해 재생할 수 있습니다. 영상 렌더러는 각 프로젝트의 `film` 데이터로 제목·미리보기·영상 ID를 설정합니다.

한강터의 소개와 수상 내역은 사용자가 제공한 공공 정보 브랜딩 시스템 설명 및 2026 Red Dot Design Brand Communication Junior Award | Winner 문구를 반영했습니다.

이미지는 `dist/assets/`, 이미지 설명과 표시 크기는 `dist/assets.js`와 `dist/weave-assets.js`에 있습니다. `prepare-assets.cjs`와 `prepare-weave-assets.cjs`는 제공된 원본을 보존하며 WebP 사본을 생성합니다. 실행 시 설치된 sharp 모듈의 경로를 인수로 전달합니다.

GRIPS는 홈 오른쪽 목록과 Projects 및 Index의 Product 분류에 나타납니다. 제품 렌더링을 썸네일과 상세 갤러리의 첫 이미지로 사용하며, 상세 주소는 `#/project/grips`입니다. 이미지 9장의 정보는 `dist/grips-assets.js`에서 관리합니다.

위브 키친은 홈 오른쪽 목록의 첫 프로젝트와 Projects, Index의 Product 분류에 나타납니다. 상세 주소는 `#/project/weave-kitchen`입니다. 제작 연도는 제공되지 않아 표기하지 않았습니다. 프로젝트별 이미지 갤러리와 영상은 공통 렌더러를 사용하며 각 프로젝트에 연결된 미디어를 표시합니다.

Projects에서는 썸네일에 마우스를 올리거나 카드에 키보드로 초점을 주면 갤러리 이미지가 순서대로 재생됩니다. 마우스를 떼거나 초점을 옮기면 썸네일로 돌아가며, 모션 줄이기 설정에서는 정지 이미지를 표시합니다.

분야 필터, 프로젝트 인덱스 미리보기, 상세 갤러리, 다음 프로젝트, 뒤로 가기, 모바일 레이아웃과 모션 줄이기를 지원합니다.

베지밀 상세 주소는 `#/project/vegemil`입니다. 홈 왼쪽에서 한강터 다음에 나타나며, Projects와 Index의 Brand identity 분류에 표시됩니다. 제작 연도는 제공되지 않아 상세 페이지에서 생략했습니다. 제공된 전체 제목과 대한디자인전람회 특선 문구를 상세 설명에 표시합니다.

`prepare-vegemil-assets.cjs`는 원본을 보존하며 WebP 이미지 22장을 만들고 `dist/vegemil-assets.js`에 설명과 크기를 기록합니다. 기존 이미지 스크립트처럼 sharp 경로를 인수로 전달합니다. `prepare-vegemil-video.cjs`에는 설치된 FFmpeg 실행 파일 경로를 전달합니다. 원본 영상을 1080p H.264/AAC, 2-pass 1500kbps 비디오와 128kbps 오디오, fast-start MP4로 변환합니다. 웹용 사본은 `dist/assets/vegemil-film.mp4`이며 영상 전체 길이와 오디오를 유지합니다. 상세 페이지의 HTML5 플레이어는 사용자 조작으로 재생되며, 재생 전에는 영상을 내려받지 않습니다. 로컬 서버는 MP4 Range 요청을 지원합니다.
