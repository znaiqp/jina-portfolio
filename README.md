# HANGANG TUH — Portfolio

ORKR의 절제된 타이포그래피, 분할 레이아웃, 고정 내비게이션과 프로젝트 중심 탐색에서 영감을 얻은 정적 포트폴리오입니다.

실행: `node server.mjs` → http://127.0.0.1:4173

배포할 파일은 `dist/`에 있습니다. 의존성이나 빌드 과정이 필요하지 않습니다.

- `dist/app.js`: 프로젝트 목록, 소개 문구, 화면과 인터랙션
- `dist/style.css`: 반응형 레이아웃, 호버와 모션
- `dist/index.html`: 사이트 이름, 메타데이터와 내비게이션

한강터 프로젝트는 제공된 이미지 7장으로 구성했습니다. 다른 프로젝트 7개와 소개 문구는 예시입니다. 실제 연락처는 아직 포함되지 않았습니다.
이미지 자리에는 사각 테두리와 두 개의 대각선으로 된 SVG 플레이스홀더가 있습니다. 이미지 추가 시 placeholder 함수를 수정하세요.

홈의 좌우 목록은 각각 독립적으로 스크롤되며, 프로젝트 제목이 각 목록 상단에 고정됩니다. 모바일은 하나의 세로 문서로 전환됩니다. 상단으로 이동하면 양쪽 목록이 함께 초기화되고, 상세 페이지에서 돌아오면 스크롤 위치가 복원됩니다.

한강터 영상은 `https://youtu.be/XqM5RE9RETE`의 클릭 재생 YouTube 임베드입니다. 홈 오른쪽 목록과 한강터 상세 페이지에서 재생할 수 있습니다. 외부 YouTube 링크도 제공됩니다.

이미지는 `dist/assets/`, 원본 파일명·설명과 표시 크기는 `dist/assets.js`에 있습니다. `prepare-assets.cjs`는 제공된 원본을 보존하며 WebP 사본을 생성합니다. 실행 시 설치된 sharp 모듈의 경로를 인수로 전달합니다.

분야 필터, 프로젝트 인덱스 미리보기, 상세 갤러리, 다음 프로젝트, 뒤로 가기, 모바일 레이아웃과 모션 줄이기를 지원합니다.
